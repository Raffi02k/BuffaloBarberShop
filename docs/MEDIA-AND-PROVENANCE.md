# Source and media provenance

The previous deliverable was a self-contained HTML preview, not a complete repository. This delivery reconstructs its component modules as ESM TypeScript/TSX with JSX, preserves CSS/media and adds source configuration, contact/API integration, safe demo labels and FastAPI. It is not represented as an untouched original Git repository.

The old router adapter/embedded React runtime is not shipped as this app's dependency setup. package.json declares actual React/react-dom/react-router-dom packages, installed by npm. The app does not load the entire old HTML in an iframe.

Images were supplied in the conversation or extracted from the earlier preview of those images. Ownership/publication permission has not been verified here. Reference salon/craft images are not automatically photographs of Buffalo. The video animates still photos and is not actual salon footage.

No font binaries are included. Google Fonts is requested externally with system fallback. Dependency licenses accompany packages when installed. This delivery grants no new rights to third-party images, trademarks, fonts or likenesses.

Unverified aggregate review ratings and alleged real review excerpts were replaced with visibly labeled DEMO cards. API reviews start empty. Missing personal details remain placeholders; no portrait is assigned to a different person.
